# Global Search - Quick Start Guide

## 🚀 Getting Started

The Global Search feature is available on the **Overview Dashboard** for **Admins** and **Managers**.

## 📍 Where to Find It

1. Log in to the ASHCOL Portal
2. Navigate to **Dashboard** (Overview page)
3. Look for the search bar at the top of the page

```
┌──────────────────────────────────────────────────────────┐
│  🔍  Search customer name, ticket number, branch...      │
└──────────────────────────────────────────────────────────┘
```

## 🔍 How to Search

### Step 1: Type Your Query
Simply start typing in the search bar. You can search for:
- Customer names: "Juan", "Maria Santos"
- Ticket numbers: "TKT-12345"
- Branch names: "Robinsons", "SM"
- Technician names: "Mario", "Pedro"
- AC types: "Daikin", "Samsung"
- Service types: "Installation", "Repair"
- Status: "Completed", "Pending"

### Step 2: View Results
Results appear instantly in a dropdown below the search bar.

**Each result shows:**
- 📄 Customer name
- 🎫 Ticket/Control number
- 🏢 Branch/Store
- 🔧 Service type
- 👷 Technician
- ✅ Status (color-coded)
- 📅 Last updated

### Step 3: Filter Results (Optional)
Use the filter chips to narrow down results:
- Click **"Tickets (X)"** to show only tickets
- Click **"Service Reports (Y)"** to show only service reports
- Click **"Clear filters"** to show all results again

### Step 4: View Details
Click **"View Details →"** on any result to open the full information modal.

## 💡 Search Tips

### ✅ DO:
- Use partial words: "Rob" finds "Robinsons"
- Mix upper/lowercase: "JUAN" = "juan" = "Juan"
- Search multiple fields: Results match any field
- Use specific terms for better results

### ❌ DON'T:
- Don't use special characters unnecessarily
- Don't worry about exact spelling
- Don't include extra spaces

## 🎨 Status Colors

Results are color-coded by status:

## ⌨️ Keyboard Shortcuts

- **Type** to search (no need to click)
- **Esc** to close results dropdown
- **Click outside** to close modal

## 📱 Mobile Usage

The search works great on mobile:
- Tap the search bar
- Type your query
- Scroll through results
- Tap "View Details"
- Swipe to close modal

## ❓ FAQ

**Q: Why don't I see the search bar?**  
A: The global search is only available for Admin and Manager roles.

**Q: Can I search for multiple things at once?**  
A: Yes! Type any keyword and it searches all fields simultaneously.

**Q: How do I clear my search?**  
A: Click the X button on the right side of the search bar.

**Q: Can I export search results?**  
A: Not yet, but this feature is planned for a future update.

**Q: Why are some results missing information?**  
A: Some fields may be optional or not filled in for certain records.

**Q: Can I search by date?**  
A: Currently, you can search by typing dates, but date range filtering is coming soon.
